Most of what I build sits between three questions: how does an intelligent system actually work, how do you measure whether it's any good, and how do you keep it from being easy to abuse. A password-hashing study, an authorized web-app security tool, a reinforcement-learning agent that plays Snake, and a sealed digital time capsule are each an attempt at one piece of that, from a different angle.

**Currently studying:** large language models, retrieval-augmented generation, secure application development, cloud, and system design.

## Projects

| Project | What it does | Status |
|---|---|---|
| **[Password Security Lab](https://github.com/denyelcnamgyal42-hash/password-security-research-lab)** | Compared hashing algorithms under a dictionary attack on 1,000 fake accounts. MD5 gave up 172 passwords; Argon2id gave up 61. No real credentials — isolated lab only. | Complete |
| **SentinelAI** | An AI-assisted tool for authorized web application testing. The goal is a report a person can stand behind, not a dump of scanner noise. | In progress |
| **[RL Snake](https://github.com/denyelcnamgyal42-hash/snake_game_reinforcement_learning)** | A reinforcement-learning agent that learns to play Snake from scratch — a small board where I can watch an agent fail, then improve. | Complete |
| **Until Then** | A digital time capsule. Shared memories stay locked until a date the people who made them chose. | In progress |
