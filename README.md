## Brief

Computer Science student in Bhutan. I work at the overlap of **artificial intelligence**, **cybersecurity**, and **software engineering** -- not as three separate interests, but as one question:

> Can we build systems that are capable, inspectable, and hard to abuse?

I learn by running experiments. A controlled study is more useful to me than another cloned tutorial.

## Selected work

**[Password Security Research Lab](https://github.com/denyelcnamgyal42-hash/password-security-research-lab)**  
`cybersecurity` `python` `completed`

A controlled study of password hashing under dictionary attack. Synthetic dataset, 1,000 accounts, isolated lab -- no real credentials.

| Algorithm | Recovered |
| --- | ---: |
| MD5 | 172 / 1000 |
| SHA-256 | 172 / 1000 |
| bcrypt | 65 / 1000 |
| Argon2id | 61 / 1000 |

Fast hashes make guessing cheap. Memory-hard hashes make it expensive. That is the whole argument, measured.

`ai` `security` `in progress`
