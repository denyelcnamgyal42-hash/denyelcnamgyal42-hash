## About

Most of what I build sits between three questions: how does an intelligent system actually work, how do you measure whether it's any good, and how do you keep it from being easy to abuse. A password-hashing study, an authorized web-app security tool, a reinforcement-learning agent that plays Snake, and a sealed digital time capsule are each an attempt at one piece of that, from a different angle.

**Currently studying:** large language models, retrieval-augmented generation, secure application development, cloud, and system design.
